## Log format

Per set in Hevy, start the routine the pointer names from the `Rotation 2026-10` folder that `tools/hevy_push_routines.py` creates; the routine titles start with the slot (L1 Lower A, ..., Full C) so `tools/update_tracks.py` maps each workout onto the rotation. Use Hevy's RPE field on top sets at minimum. After each pass, run `python3 tools/hevy_sync.py` (pull, apply the rules, push the new loads); it updates `tracks.json`, the table above and `data/track-log.md`. The Markdown fallback is `templates/log-template.csv`.
