# Check-in records

One file per Sunday check-in, named `YYYY-MM-DD.md`, written by `coach/sunday-checkin.md`. Each records the lifter's answers (readiness 1-5 for sleep, soreness, stress, joint pain; bodyweight in lb; days available), the recap of the week before, flags counted, and every rule that fired with its section in `templates/progression-tracks.md` or `guide/03-flexible-scheduling.md`.
